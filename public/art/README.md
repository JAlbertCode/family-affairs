# Character art

Drop character art here as `<id>.png` and it appears behind the card automatically.
Missing files are ignored, so you can add them one at a time.

    amanda.png     chichi.png    dainese.png   dorian.png
    gabby.png      grandma.png   jay.png       manny.png
    mikeymoe.png   titibibi.png  titibum.png   xavi.png

The ids come from `src/engine/cards/characters.ts` (the `art:` field).
Roughly 3:4 portrait crops read best at card size.
